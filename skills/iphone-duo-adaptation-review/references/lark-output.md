# 飞书交付

读可用 lark-doc/lark-wiki 或文档写入 skill，按指定文档库新建报告，更新已有目标时保留独有内容和旧版。无默认历史目标。

lark-blocks.json 原生标题/正文/超链接/上传后的标注图片依序写入。文字可编辑；官方依据原生链接、中文摘要分段，多张代表图覆盖现象，汇总页不重复长说明。媒体先上传再插对应块，不依赖临时FigmaURL，不把本地路径当已发布图。只发布脱敏标注图，不自动上传原视频、原图、日志。

后台 evidence_key 映射到文档 block ID；publication.json 保存URL/token、版本、report hash及组/页块映射。完整回读图片序列、标号、引用、正文，必要时查渲染。失败依据具体错误修复最多两次；权限/目标缺失补问、保留本地稿明确未发布。
